Dice

A calm library for your emulator games on GNOME.

Point Dice at your ROM folder: it finds your GBA, DS, 3DS, PS1, PSP and PS2 games, shows them with their box art, and launches each one in the right emulator.

Install

Install with GNOME Software

Opens GNOME Software (or your distro's app store) and adds this repository, so Dice updates like any other app.

Or from a terminal

flatpak remote-add --user --if-not-exists dice \
    https://drvonmiau.github.io/dice/index.flatpakrepo
flatpak install --user dice io.github.drvonmiau.Dice

Updates then arrive with flatpak update. You need Flatpak, which most Linux distributions already have. Emulators are installed separately — for example mGBA, melonDS, PPSSPP or PCSX2 from Flathub.

About

Dice doesn't include, download or link to any games. It organises and launches backups of games you own. Free software under the GPL 3.0 or later.
